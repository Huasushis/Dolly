# ADR 0003: Stable Core and Research boundary

- Status: Accepted

## Decision

Memory association, adaptive scheduling, `tensity`, reflection, procedural
memory, abstraction/trajectory transfer, browser-agent evaluation, learning
interventions, framework comparisons, autonomous role assignment, and topology
evolution remain optional research capabilities. They cannot control
durability, identity, ordering, authorization, reference validity, or physical
GC.

## Rationale

The owner explicitly described these as hypotheses requiring comparison and
ablation. Encoding them as Core correctness would make unvalidated intuition a
production guarantee and obstruct negative experimental results.

## Promotion

Research advances through shadow and canary stages with preregistered efficacy,
safety, cost, latency, resource, and recovery gates. Stable adoption requires a
new ADR and compatibility plan.
